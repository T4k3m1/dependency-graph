## Правила оформления Git

| Правило | Проверка |
| --- | --- |
| С1-С5 | README.md, .gitignore, src, tests, run.bat и run.sh |
| С6 | Отдельные подробные feat(scope)-коммиты |
| Г1-Г5 | Нет архивов, бинарников, служебных файлов, сборки, настроек редакторов |
| Р1 и Р6 | До 1000 строк в файле, до 120 символов в строке Java |
| Ф4, А4 | До 40 строк в методе, до 7 параметров |
| К4 | Javadoc у классов и методов |
| Ц4, М4, И4 | Сложность до 10, MagicNumber, Java-соглашения имён |
| Остальные языковые правила | Неприменимы: исходники и тесты на Java |

Сохранённые текстовые результаты в docs - примеры документации.
SVG и D2-файлы демонстраций передаются отдельно от Git-репозитория.
Архив передачи находится снаружи репозитория и не добавлен в историю.
Закрытая программа преподавателя недоступна; её результат не гарантируется.
