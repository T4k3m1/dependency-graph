# Проверка варианта 11

Дата: 09.11.2026. JDK 25.0.2, компиляция --release 17.
Рендерер D2 0.9.0, Checkstyle 10.21.4 с конфигурацией checkstyle.xml.
Эталонная среда pip: CPython 3.12.14, Windows AMD64.

Проверено:

- CLI и ошибки пяти обязательных параметров.
- Самостоятельный JSON-разбор, версии, маркеры, HTTP и явные конфликты.
- BFS с рекурсией по уровням, ромб, циклы, самоссылка, лист и неизвестная вершина.
- Широкий граф 4001 вершина и защита от чрезмерной глубины рекурсии.
- Порядок установки с зависимостями до родителей и ошибка для циклов.
- Текст D2, реальные SVG для A, F, G, I, включая путь с пробелами.
- Настоящие графы requests, rich, packaging сравнены с pip inspect и pipdeptree.
- Совпадение версий, вершин и рёбер всех трёх реальных примеров.
- Порядок pip сравнен с нашим; независимые листья допустимо расположены иначе.
- Визуально просмотрены SVG: подписи и стрелки читаемы, обрезаний не обнаружено.
- Checkstyle: ноль нарушений в src и tests.
- Каждый из пяти коммитов проверен отдельно: структура, формат сообщений,
  отсутствие запрещённых файлов, длины файлов/строк, Java-правила и тесты своего этапа.
- Восстановленная из архива чистая копия проходит тесты и проверку SVG.
- Рабочая копия Git чистая, исходники и тесты только Java.
- У репозитория нет удалённого адреса, публикация не выполнялась.

Готовые изображения вынесены из Git. ZIP передачи также снаружи репозитория.

отслеживаемыми исходными файлами и должны сохраняться при передаче.
